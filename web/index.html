Features

Everything you need
to stay informed.

A complete real-time overview of all active ATC stations across the entire IVAO network.

📡

Live ATC List

Browse every active controller worldwide. See callsigns, station names, country flags, frequencies, and how long each controller has been online — updated automatically every 15 seconds.

🗺️

Interactive Coverage Map

Visualize ATC coverage on a satellite map. Tower and ground stations appear as markers, while approach and center stations display their actual airspace boundaries as polygon overlays.

📋

ATIS Information

Read the full ATIS broadcast for any station. See current weather, active runways, approach types, and the ATIS revision letter — exactly what pilots see when tuning the frequency.

✈️

Pilot Tracking

See all pilots currently flying in each controller's airspace. View their callsign, altitude, heading, ground speed, and planned route from departure to arrival on the map.

🔍

Smart Search

Instantly filter controllers by callsign prefix. Looking for all German stations? Type "ED". Want Istanbul? Type "LT". Your last search is remembered between sessions.

📱

Designed for Every Screen

Optimized layouts for iPhone, iPad, and Mac. On iPhone you get a focused list with push navigation. On iPad and Mac, enjoy a split-view with the ATC list alongside a live map.

How it works

Simple. Fast. Real-time.

Data is pulled directly from the official IVAO API, so you always see exactly what's happening on the network.

Open the app

Launch IVAO Active ATC and instantly see every controller currently online across the entire network.

Search or browse

Filter by callsign prefix to find specific regions, or scroll through the full list sorted alphabetically.

Tap for details

Select any controller to see their coverage area on the map, full ATIS text, frequency, position type, and active time.

Monitor traffic

See inbound, outbound, and in-region pilot counts. Tap any pilot on the map to view their flight plan and route.
